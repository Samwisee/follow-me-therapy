# Field

Somewhere to type on a screen: a name, a note, a reminder time. On paper the same place is writing lines (`WriteLines`).

- **Looks like somewhere to write:** a `border-outline` **dashed** outline on all four sides in `field-line`, corners `radius-sm`, paper inside, at least the 44px target tall.
- While typing, the outline turns solid `field-line-focus` (purple), with the focus ring around it.
- The hint (placeholder) is `field-placeholder`, what's typed is `field-ink`; a field always has a label (visible, or `aria-label`).
- **Time field:** the time with the `clock` icon. Tapping it opens the device's own clock (`<input type="time">`: a dial on Android, wheels on iPhone), so nobody has to type a time. Times show as people say them: 7:30am, 4pm.
- In code: `<Field label="Activity 1" placeholder="Activity 1" />`, `<TimeField label="Reminder time" value="07:30" />`.
