# Logo

The Follow Me Therapy mark and its two lockups, as vector files in the Logos group.

- Pick the file by shape: `lockup-stacked` for covers and square spaces, `lockup-horizontal` for headers and footers, `mark` alone where the name is already on the page.
- Pick the ink by ground: the `ink` files on light grounds, the `-white` files on `deep`, `purple` or `teal`.
- The `Logo` component draws the mark from vector shapes in `brand-ink` (the same token as the name), so it can't fall out of step. Outside React, place the SVG files with `<img>` at a set height; never set both width and height.
- On the A4 worksheet footer use `lockup-horizontal` at 9 mm tall; on a book cover use `lockup-stacked` at 40–60 mm wide.
- In code: `<Logo variant="stacked" height={110} />`; `inverse` for white on dark grounds.
