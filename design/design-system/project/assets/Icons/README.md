Line icons from the website, drawn in `ink` (#2b2540) on a transparent ground; an `<img>` can't recolour them. For a coloured icon, paste its paths into an inline `<svg>` with `stroke: currentColor` (see IconTile). 40×40 service and funding icons: `footprints` (filled; 5 Steps Forward), `stairs` (Steady Steps), `blocks` (ESDM), `clipboard` (Assessments), `umbrella` (NDIS), `medicare-cross` (Medicare), `shield-tick` (Private). 24×24 inline icons: `smile` (ages), `video` (telehealth), `pin` (in person), `tick`, `chevron`, `heart` (the promise), `book` (evidence), `info`.
