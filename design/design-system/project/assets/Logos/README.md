Vector logo files (SVG), each in `ink` (#2b2540) and white: `mark`, `lockup-stacked` and `lockup-horizontal`. The lettering is outlined, so they print without the fonts. The mark is traced from the original 271×300 PNG (`follow-me-therapy-mark.png`), which is kept for reference only; use the SVGs everywhere. A single-ink file can't be recoloured through `<img>`, so pick the ink or the white file.

The horizontal lockup carries the descriptor: **Follow Me Therapy** and **Paediatric Occupational Therapy** are set to one width, and the two lines together are exactly the mark's height (the name's cap top level with the top of the mark, the descriptor's baseline level with its foot), so the descriptor stays readable wherever the logo is small, like a worksheet's footer. `tools/make_lockups.py` builds it that way.
